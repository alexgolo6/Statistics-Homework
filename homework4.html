Exercise 1 – Welford's Recurrence Formulas

The goal is to calculate the mean and variance while the observations arrive one by one. Instead of storing all the values and recalculating everything after each new observation, Welford's method updates the results using the previous values.

1. Deriving the formulas

Suppose that after observing n values, I already know their mean Mn and the sum of squared deviations:

SSn = Σ (xi − Mn)²

Now a new observation x arrives. I define the difference between this value and the old mean:

δ = x − Mn

The new mean is the new sum divided by the new number of observations. The old sum is n·Mn, so:

Mn+1 = (n·Mn + x) / (n + 1) = Mn + (x − Mn) / (n + 1) = Mn + δ / (n + 1)

This is Knuth's recurrence for the mean: the new mean is the old mean plus a correction proportional to δ. I follow the same idea for the sum of squares and for the variance.

After updating the mean, I calculate the difference between the new value and the new mean:

δ₂ = x − Mn+1

To update the sum of squares, I use the fact that the deviations from the old mean add up to zero. Replacing the old mean with the new mean changes the sum of squares of the previous observations by nδ²/(n + 1)². The new observation contributes n²δ²/(n + 1)². Adding these two changes gives nδ²/(n + 1), which is equal to δ · δ₂. Therefore:

SSn+1 = SSn + δ · δ₂

The sample variance of n values is the sum of squares divided by n − 1:

s²n = SSn / (n − 1)

To get a recurrence for the variance itself, I divide SSn+1 by n and replace SSn with (n − 1)·s²n (this works for n ≥ 2):

s²n+1 = ((n − 1) / n) · s²n + δ² / (n + 1)

In the code below I keep SS and compute the variance as SS / (n − 1), which is equivalent.

The main idea: I only need to remember the number of values, the current mean and the current sum of squares. Each new observation updates these three quantities.

2. The code

The core update is only 3 lines (delta, mean and SS), plus the counter n++. Here, mean stores the current mean and SS stores the sum of squared deviations.

n++;
const delta = x - mean;
mean += delta / n;
SS += delta * (x - mean);

The code uses the updated mean in the last line. This is important for Welford's formula.

5. Interpretation and conclusion

The average of the sampling means should be close to the theoretical mean, 5. The average of the sample variances should also be close to the theoretical variance, 10. The values will not necessarily match exactly because each hacker receives a different random sample and only a finite number of hackers is included in the simulation.

Conclusion from the comparison. Both averages end up very close to μ and σ². This means that the sample mean and the sample variance (with n − 1) are unbiased estimators: their expected values are exactly μ and σ², for any n. A single hacker can be above or below the true value, but the errors cancel on average. If the variance were divided by n instead, its average would be only about (n − 1)/n · σ² (about 9 for n = 10), which is why n − 1 is used. This is useful in inferential statistics because in practice we have only one sample and not m of them: unbiasedness tells us that the estimate has no systematic error, and the spread of the estimates tells us how much to trust it.

When n increases, each hacker has more observations. This usually makes the individual sampling means less spread out and closer to 5. The sample variances also tend to become less variable across hackers, although they can still differ from one sample to another. For the mean this is exact: its standard deviation is σ/√n, so it shrinks with the square root of n (here about 1.00 for n = 10 and 0.32 for n = 100).

One thing I noticed in this experiment is that increasing the number of systems and increasing the number of hackers do not do the same thing. More systems make each hacker's estimates more stable, while more hackers make the averages across hackers more reliable. This is useful in inferential statistics because we often cannot measure an entire population. Instead, we use samples to estimate its characteristics. Welford's method makes it possible to calculate the sample mean and variance efficiently as each new score is received.
