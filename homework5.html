Homework 5: Numerical Integration and Normal CDF

In this homework, I compare two numerical ways of thinking about integration: dividing the domain into small intervals and dividing the range of function values into levels. I also implement Simpson's rule to calculate values of the standard normal CDF and compare them with a reference table. I kept the examples relatively simple, but included a few functions that show why the two definitions of integration are not always interchangeable in a straightforward numerical experiment.

Exercise 1 – Riemann and Lebesgue Integration

The integral can be understood as the area under a function. The Riemann approach divides the x-domain into small intervals. The Lebesgue approach groups points according to the values of the function and measures the corresponding subsets of the domain.

1. The two numerical approaches

Riemann-inspired method – partitioning the domain

I divide [a,b] into N equal intervals and use the midpoint of each interval to estimate the rectangle height:

Integral ≈ Σ f(xᵢ*) · Δx

Here, Δx is the width of an interval and xᵢ* is its midpoint.

Lebesgue-inspired method – partitioning the range

For a non-negative bounded function, I use the layer-cake idea: I divide the range of function values into K horizontal levels. For each level y, I estimate the length of the set of x-values for which f(x) is at least y.

Integral = ∫₀ᴹ measure({x : f(x) > y}) dy

In the numerical version, the measure of each preimage is estimated by counting sample points in the domain. This is an approximation inspired by the Lebesgue definition, not a full implementation of measure theory.

4. Pathological examples and their meaning

Thomae: 1/q at reduced p/q, 0 on irrationals00It is Riemann-integrable, even though it is discontinuous at every rational number.

Important numerical limitation: a computer grid uses finitely many points, and the grid points are rational when represented as fractions. A direct test of the Dirichlet function on such a grid would return 1 at every sampled point, suggesting an integral of 1. This is misleading: the rational numbers have measure zero, so the Lebesgue integral is 0. The finite grid cannot represent this difference. For this reason, I discuss the Dirichlet function theoretically instead of presenting the grid result as a valid Lebesgue approximation.

Thomae's function is different. Its values at rational sample points become small as the denominators increase, so numerical sums can move towards 0. It is a useful example of a function that is Riemann-integrable despite having many discontinuities.

5. Accuracy, convergence and efficiency

For continuous functions and the step functions used here, both numerical approaches should approach the same integral when the partitions are refined. The midpoint method uses N function evaluations. The range method evaluates the function on a domain grid, groups the values into K levels and then counts the points above each level. With a histogram and cumulative counts, this takes about N + K simple steps, and its result depends on both N and K. A larger K gives a finer range partition, while a larger N gives a better estimate of the measure of each preimage.

For functions with jumps, the position of the partition points can affect the error, but the integral is still recovered as the partitions become finer. The Dirichlet example shows a more fundamental difference: it is not Riemann-integrable, even though its Lebesgue integral exists.

Exercise 2 – Numerical Computation of the Normal CDF

1. Definition of the standard normal CDF

The standard normal distribution has mean 0 and standard deviation 1. Its probability density function is:

φ(t) = (1 / √(2π)) · e^(−t²/2)

The cumulative distribution function gives the probability that a standard normal random variable is less than or equal to x:

Φ(x) = ∫₋∞ˣ φ(t) dt

Because the density is symmetric around zero, Φ(0) = 0.5. For a positive x, I can integrate from 0 to x and add 0.5. For a negative x, I use symmetry and subtract the area from 0 to |x| from 0.5.

2. Numerical method: composite Simpson's rule

I use Simpson's rule to approximate the integral from 0 to |x|. It divides the interval into an even number of subintervals and approximates the curve using parabolas.

∫ₐᵇ f(t)dt ≈ h/3 · [f₀ + fₙ + 4(f₁ + f₃ + ...) + 2(f₂ + f₄ + ...)]

Here, h = (b − a)/n and n must be even. The method is more accurate than a simple rectangle approximation for a smooth function such as the normal density.

The implementation uses symmetry:

Φ(x) = 0.5 + integral(0 to x), if x ≥ 0
Φ(x) = 0.5 − integral(0 to |x|), if x < 0

3. Why is there no elementary formula?

The normal CDF contains the integral of the Gaussian exponential function. Liouville's theorem from the theory of elementary integration explains why this antiderivative cannot be written using only elementary functions such as polynomials, exponentials, logarithms and trigonometric functions. The theorem gives mathematical conditions for an elementary antiderivative to exist; applied to the Gaussian function, those conditions cannot be satisfied.

This does not mean that the integral has no exact mathematical representation. The error function, called erf, is a special function defined by:

erf(x) = (2/√π) · ∫₀ˣ e^(−t²) dt

The normal CDF can therefore be written exactly as:

Φ(x) = 0.5 · [1 + erf(x/√2)]

In practice, a computer still needs an algorithm to evaluate erf or the integral. Numerical integration, series expansions and specialised approximations are common options. In this homework I implement Simpson's rule because its steps are clear and it works well for the smooth normal density.

6. Accuracy and computational efficiency

Simpson's rule uses more function evaluations when the number of subintervals increases. For a smooth function, the approximation error generally decreases quickly as the interval is refined. The calculation is still lightweight for the values used here. The table above compares the numerical results with NIST values rounded to five decimal places, so very small differences can also come from the rounding of the reference table.

Other possible methods include the power series of the error function and specialised approximations to erf. A series can be accurate near the origin but may need many terms for larger inputs. Specialised approximations can be faster, but they require more formulas and care with numerical error. Simpson's rule is a straightforward method to implement and understand.
